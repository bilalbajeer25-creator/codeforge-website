01 - How Ezoic Earning Works

Basic Concept: How Websites Earn from Ads

When someone visits your website, ads are shown on the page. Advertisers pay money to show their ads to your visitors. The ad network (like Ezoic) takes a small commission and gives you the rest. This is how every ad-supported website earns money - from blogs to YouTube to news sites.

Key Terms You Must Know

CPM (Cost Per Mille / Cost Per 1000 Impressions)

This is how much an advertiser pays for 1000 ad views. If CPM is $5, it means for every 1000 times the ad is shown, the advertiser pays $5. Developer/tech content typically has CPM between $3 to $15, which is higher than entertainment or gaming content.

RPM (Revenue Per 1000 Pageviews)

This is how much YOU earn per 1000 page views. RPM is usually higher than CPM because each page has multiple ad slots. If your page has 4 ads and each has $3 CPM, your RPM could be around $8-$12 after the ad network's commission.

EPMV (Earnings Per Thousand Visitors) - Ezoic's Metric

Ezoic uses EPMV instead of RPM because it measures earnings per visitor, not per pageview. This is more accurate because one visitor might view 3 pages. If EPMV is $10 and you get 1000 visitors, you earn $10. Ezoic's EPMV for tech sites is typically $8-$25.

02 - Ad Network Signup Process

Recommended Strategy: Start with Adsterra, Upgrade to Ezoic

Best Plan: Apply to Adsterra first (instant approval) to start earning immediately. Then apply to Ezoic simultaneously. Once Ezoic approves, switch to Ezoic for higher earnings. You can also apply to Media.net as a backup.

A. Adsterra Signup (Fastest - Instant Approval)

1

Go to adsterra.com

Visit https://www.adsterra.com and click "Sign Up" or "Start Earning". Select "Publisher" account type (you are a website owner showing ads, not an advertiser).

2

Fill in Your Details

Enter your name, email, and website URL (your Vercel domain like codeforge.vercel.app). Select payment method (choose Payoneer or Wire Transfer). Adsterra accepts Pakistani publishers.

3

Get Your Zone IDs (Instant)

After signup, go to Dashboard > Add Website > Create Ad Zone. Create these zones:
- Banner 728x90 (for horizontal ads) → Copy the Zone ID
- Native Ad (for in-article ads) → Copy the Zone ID
- Social Bar / Sticky (for mobile) → Copy the Zone ID

4

Put Zone IDs in .env.local

Add your Zone IDs to the environment variables (explained in Section 03). Your ads will start showing within minutes!

B. Ezoic Signup (Highest Earning)

1

Go to ezoic.com

Visit https://www.ezoic.com and click "Get Started". Ezoic offers a free tier called "Access Now" that has no minimum traffic requirement.

2

Enter Your Website URL

Enter your deployed website URL (e.g., codeforge.vercel.app). Ezoic will scan your site for compliance - policy pages, original content, no prohibited content.

3

Wait for Approval (1-3 Days)

Ezoic reviews your site. CodeForge has everything they need: original blog posts, working tools, Privacy Policy, Terms & Conditions, Disclaimer, About page. Approval rate is very high for developer sites.

4

Get Your Ezoic Site ID

After approval, go to Ezoic Dashboard > Settings. You will find your Site ID. Copy this and add it to your .env.local file as NEXT_PUBLIC_EZOIC_SITE_ID.

5

Choose Integration Method

For Next.js on Vercel, choose "Cloudflare Integration" or "DNS Integration". Ezoic will walk you through connecting your domain. If using .vercel.app domain, use Ezoic's JavaScript tag integration instead.

C. Media.net Signup (Backup Option)

1

Go to media.net

Visit https://www.media.net and apply. Media.net is Yahoo! and Bing's ad network. They prefer sites with some traffic (even 500 visitors/month is enough). Approval takes 2-5 days.

2

Get Your CID

After approval, you get a CID (Customer ID) from the dashboard. Add it to .env.local as NEXT_PUBLIC_MEDIANET_CID.

03 - Ad Code Setup in CodeForge

Environment Variables Configuration

CodeForge already has ad components built in. You only need to configure which ad network to use by setting environment variables. This is done without changing any code.

Step 1: Create .env.local file

In your project root folder, create a file named .env.local:

# Which ad network to use: "adsterra" or "ezoic" or "medianet" or "none"
NEXT_PUBLIC_AD_NETWORK=adsterra

# ---- ADSTERRA (Start with this) ----
NEXT_PUBLIC_ADSTERRA_BANNER_ID=your_banner_zone_id_here
NEXT_PUBLIC_ADSTERRA_NATIVE_ID=your_native_zone_id_here
NEXT_PUBLIC_ADSTERRA_STICKY_ID=your_sticky_zone_id_here

# ---- EZOIC (Upgrade to this later) ----
NEXT_PUBLIC_EZOIC_SITE_ID=your_ezoic_site_id_here

# ---- MEDIA.NET (Backup option) ----
NEXT_PUBLIC_MEDIANET_CID=your_medianet_cid_here

Step 2: Replace with your real IDs

After signing up on Adsterra/Ezoic, replace the placeholder values with your actual IDs. For example, if Adsterra gives you Banner Zone ID 1234567, set:

NEXT_PUBLIC_ADSTERRA_BANNER_ID=1234567

Step 3: Restart the development server

Environment variables only take effect after restarting the server. Stop the current server and run again:

npm run dev

Switching Between Ad Networks

To switch from Adsterra to Ezoic, simply change the environment variable:

NEXT_PUBLIC_AD_NETWORK=ezoic

That's it! The ad components will automatically switch to Ezoic code. No other code changes needed.

04 - Deploy on Vercel (Free Hosting)

Complete Deployment Steps

1

Install Git

Download and install Git from https://git-scm.com. After installation, open terminal and set your identity:

git config --global user.name "BILAL"
git config --global user.email "your-email@gmail.com"
2

Create GitHub Account

Go to https://github.com and create a free account. Use the same email you used in Git config. Verify your email address.

3

Upload Code to GitHub

Open terminal in your project folder and run these commands:

cd /path/to/your/codeforge-project

# Initialize git repository
git init

# Add all files
git add .

# Create first commit
git commit -m "Initial commit - CodeForge website"

# Create GitHub repository first at github.com/new
# Then connect and push:
git remote add origin https://github.com/YOUR-USERNAME/codeforge.git
git branch -M main
git push -u origin main
4

Sign Up on Vercel (Free)

Go to https://vercel.com and click "Sign Up". Choose "Continue with GitHub" to connect your GitHub account. This is 100% free - no credit card needed.

5

Import Your Project

On Vercel dashboard, click "Add New" > "Project". Select your codeforge repository from the list. Vercel will auto-detect Next.js framework. Click "Deploy" - that's it! Your site will be live in 2-3 minutes.

6

Get Your Live URL

Vercel gives you a free URL like codeforge.vercel.app or codeforge-xyz123.vercel.app. This is your live website! Anyone in the world can visit it now.

7

Add Environment Variables on Vercel

Go to your project on Vercel > Settings > Environment Variables. Add all the variables from your .env.local file:

NEXT_PUBLIC_AD_NETWORK = adsterra
NEXT_PUBLIC_ADSTERRA_BANNER_ID = your_zone_id
NEXT_PUBLIC_ADSTERRA_NATIVE_ID = your_zone_id
NEXT_PUBLIC_ADSTERRA_STICKY_ID = your_zone_id

After adding, click "Redeploy" for changes to take effect.

8

Custom Domain (Optional - Free with Freenom or Cheap with Namecheap)

For a professional look, connect a custom domain like codeforge.dev or codeforge.tools. On Vercel: Settings > Domains > Add. You can buy cheap domains from Namecheap ($1-3/year for .xyz, .site domains). Free .tk/.ml domains were discontinued, so a cheap domain is the best option.

Every time you update code: Just push to GitHub with git add . && git commit -m "update" && git push. Vercel automatically rebuilds and deploys your site within 1-2 minutes!

How to Update the Website

Whenever you want to make changes (new blog post, new tool, etc.):

# 1. Make your changes in the code
# 2. Save files
# 3. Push to GitHub:
git add .
git commit -m "Added new blog post"
git push

Vercel automatically detects the changes and redeploys your site. No manual deployment needed!

07 - Important Tips & Warnings

NEVER Do These Things (Will Get You Banned)

1. Never click your own ads! This is the #1 reason accounts get banned. Ad networks have sophisticated click-fraud detection. Even one self-click can flag your account. Tell friends and family NOT to click ads either - ad networks detect this easily.
2. Never ask others to click ads! Writing "Please click on ads to support us" or "Support by clicking ads" anywhere on your site will get you banned from ALL ad networks. This violates every ad network's terms of service.
3. Never use bot traffic or paid traffic! Buying cheap traffic from Fiverr or using traffic bots will get you banned. Ad networks want real human visitors who are genuinely interested in your content. Only use the free organic methods described in this guide.
4. Never put too many ads! More ads does NOT mean more money. Too many ads make visitors leave (bounce rate increases) and ad networks may penalize you. CodeForge already has optimal ad placement - do not add more.
5. Never copy content from other sites! Duplicate content gets penalized by Google (no SEO traffic) and rejected by ad networks. Always write original content or heavily rewrite in your own words.

Things You SHOULD Do

Write 2-3 Blog Posts Per Week

Every blog post is a new page that can rank on Google. Topics: JavaScript tips, CSS tricks, React tutorials, web dev career advice. Aim for 800-1500 words per post. More content = more traffic = more earnings.

Share Every New Post on Social Media

When you publish a new blog post or tool, share it on at least 3-4 platforms. This creates initial traffic signals that help Google discover and rank your content faster.

Focus on English Content

English content earns 5-10x more than Urdu content because advertisers pay more for US/UK/Europe audiences. Write everything in English. You can add Urdu later as a secondary language.

Be Patient - It Takes Time

Every successful earning website took 6-12 months to become profitable. The first 3 months will feel slow. Keep posting, keep sharing, and the traffic will come. SEO compounds over time - month 6 will be much better than month 1.

Monitor Your Analytics

Add Google Analytics (free) to track your visitors. Also use the Ezoic/Adsterra dashboard to see which pages earn the most. Double down on what works - if a specific tool gets more traffic, create similar tools.
